# Tells

Check the screen against this list before finishing. Cut decoration. Move a fact the person still needs into a place whose name predicts it. Deleting the path to that fact is not a fix. This is the catalogue behind `SKILL.md`. Do not restate it in the reply. Fix the hits.

| Tell | What agents emit | What to do |
| --- | --- | --- |
| Obvious subtitle | A sentence under the title that defines the title | Delete it |
| Type preset | Small-caps eyebrow, title, then a second sentence, on the page and again on every section | One title. No eyebrow. No restating sentence |
| Title badge | A pill beside the title that repeats the product name | Delete the pill |
| Giant metric | A number larger than the work, when the number is not the job | If it is the job, show it once, with the comparison that gives it meaning. Otherwise shrink or delete it |
| Twin heroes | Two big figures that mean different things and look like a pair | Keep the one fact that decides the next click or the reading |
| Restated count | A big number, a caption that repeats it, and a pill that adds nothing | Keep the one that is not decoration |
| KPI card row | Three or four equal metric cards that are not the job | Remove the row. The job is the screen |
| Card wrap | A card around a stat, a card around chips, a card around the table | Alignment and a heading. Cards only for repeated objects or a real boundary |
| Nested card | A progress widget card inside a row card inside a section card | Flatten |
| Hide button | "Hide panel" as a peer of the primary action | Delete the panel from the first screen, then the button is unnecessary |
| Wrong verb | New, Edit, or Delete is the primary control when it is not the job | The job's control is primary. Other verbs stay secondary |
| Status museum | The screen only reports, and the job was an action | Put that action on the object. Do not invent an action for a screen whose job is reading |
| Lying status | Success styling on partial work, or two words that mean the same state | One true word. Partial stays visually incomplete |
| Four names | Several labels for one relationship | One word, unless the difference changes the action |
| Triple progress | Fraction plus percent plus bar for a handful of items | Named checks the person can toggle, or the fraction alone |
| Useless bar | Bars whose lengths cannot be told apart | Delete the bar |
| Empty column | A column of dashes | Drop the column. Surface a blank only when the blank is the risk |
| Calm risk | A missing critical value looks like an optional blank | Say what is missing, on that object |
| Zero chip | A filter for a value that matches nothing, same weight as the real filters | Omit it |
| Manual for a control | "Click X to filter instantly" | Make X look like a filter. Delete the sentence |
| Filters for a short list | Search plus several dropdowns for a list you can see at once | Remove them until the list is long |
| Sort dressed as a filter | A sort control sitting in the filter row, labeled like a filter | Call it a sort. Default to the order the job needs |
| Scattered work | A backlog whose unfinished items are mixed through an index order | Unfinished first only when the job is to finish them. A directory keeps the order they asked for |
| Monogram | Two-letter tile when the name is right there | Delete it. Use a real logo only if the product already has one |
| Repeated category | Category under every name and again in a filter | Keep it where it creates structure, not as a second line on every row |
| Permanent copy icon | A copy glyph on every value | Show on focus |
| Unnamed trash | Icon-only delete beside the row's only button | Name it and keep it quiet. Do not make it the primary |
| Buried delete | Managing the list, but delete exists only inside the opened record | Put the named action on the row or in a menu on that row |
| Open as the job | The row's only verb is Open, View, or Details | Keep Open for the record. Put the job verb on the row |
| Spreadsheet | Every field is a column, empty cells are dashes, copy icons sit on values, and the row has no action but Open | Show the identity and the action. Drop columns people do not compare |
| Deleted secondary | Metrics, history, or tools the person had, with no named place left | Build the panel or view and name it for what is inside. "Data" and "More" fail |
| Mystery button | A header button whose label does not say what it opens | Rename it for the contents, or merge it into that named place |
| Filler row | A placeholder row so the layout looks populated | Delete the fiction |
| Suspicious value shown as fact | Truncated identifier rendered like a confirmed one | Mark it as unverified or show it intact |
| Narrow tool | `max-w-* mx-auto` around a table or console, wide empty sides, cramped middle | Use the content width beside the shell. Cap measure only for prose |
| Missing shell | Several product areas crammed on one page, or removed so the page looks empty | Persistent side navigation, current item marked. The page keeps one area |
| Gourmet personality | A display face, gradient, or new palette on a tool whose structure is flat | Keep the existing face and one accent. Personality is the nav, the row, and the alignment |
| Fake comparison | A metric card with a badge and a caption that repeats the number, and no real series | Show a true comparison or an honest empty. Drop the badge |
| Property row | Name, category, several fields, and a button, all the same weight | One object: strong name, one quiet status, muted preview only if they scan it |
| Equal header buttons | Several filled buttons across the top | One primary. The rest quiet |
| Disclosure that is another dashboard | Tabs or a second page with the same cards and metrics | On demand means the detail of one object, or a different job |
| Page to do a button's job | A whole screen for one reversible action | A button on the existing surface |
